# KNN vs Random Forest

## Dataset Information

* Dataset: Diamond Dataset
* Rows: 54,000
* Columns: 10

## Project Description

This project compares two machine learning algorithms:

* K-Nearest Neighbors (KNN)
* Random Forest

The models were trained and tested to compare their accuracy.

## Results

* KNN Accuracy: 65%
* Random Forest Accuracy: 73%

## Conclusion

Random Forest performed better than KNN with higher accuracy and better prediction performance.
